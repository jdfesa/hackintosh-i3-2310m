Comandos practicos desde Mavericks:

No hace falta montar la EFI para estos pasos. Usar la particion visible del
instalador:

  /Volumes/Install OS X Mavericks

Red Ethernet:

1. Activar SSH:

   bash /Volumes/Install*/scripts/ssh.sh

2. Instalar Ethernet:

   bash /Volumes/Install*/scripts/red.sh

3. Reiniciar.

4. Verificar red:

   bash /Volumes/Install*/scripts/ver.sh

5. Si no funciona, generar reporte:

   bash /Volumes/Install*/scripts/diag.sh

Arranque sin pendrive:

Estado actual: resuelto.

1. Instalar EFI en disco interno:

   bash /Volumes/Install*/scripts/efi-interno.sh

2. Elegir el numero del disco interno cuando el script lo pida.
   Normalmente es 0 si el disco aparece como /dev/disk0.

3. Confirmar escribiendo SI.

Comando directo usado en el disco interno actual:

   sudo bash /Volumes/Install*/scripts/efi-interno.sh 0 SI

SSH:

1. Activar Remote Login:

   sudo systemsetup -setremotelogin on

2. Ver IP:

   ifconfig | grep "inet " | grep -v 127

3. Si SSH directo no funciona, usar la guia:

   SSH-MAVERICKS.md

Deteccion de hardware:

1. Ejecutar:

   bash /Volumes/Install*/scripts/detectar-hardware.sh

2. El script genera:

   ~/Desktop/hardware-info.txt

3. Copiarlo al instalador:

   cp ~/Desktop/hardware-info.txt /Volumes/Install*/

El reporte de diagnostico guarda un archivo red-diagnostico-*.txt en la
carpeta scripts del instalador si puede escribir ahi. Incluye kexts cargados,
interfaces ifconfig, servicios de red, deteccion de hardware, IORegistry y
logs de red.
